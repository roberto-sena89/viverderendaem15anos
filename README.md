Objetivo Final

Quero que esta aplicação tenha aparência e experiência de um produto que poderia ser vendido por assinatura (SaaS Premium). O foco é performance, design sofisticado, excelente experiência do usuário e uma arquitetura escalável.

Observação importante: Estruture o projeto seguindo boas práticas de Clean Architecture, componentes reutilizáveis, responsividade completa, acessibilidade (WCAG), documentação clara e código organizado para facilitar futuras integrações, como APIs de corretoras, atualização automática de cotações e módulos de inteligência artificial.
